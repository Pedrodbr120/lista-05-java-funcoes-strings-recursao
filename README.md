# Lista 05 - Funções, Strings e Recursão em Java

Resoluções dos dez exercícios sobre métodos com retorno, procedimentos, arrays, manipulação de strings e recursão.

Os arquivos estão em [src](src), de `Exercicio01.java` a `Exercicio10.java`. Cada classe possui seu próprio `main`, pelo menos um array, uma função com retorno e um procedimento `void`.

## Executar

Abra a pasta deste projeto no IntelliJ IDEA, selecione um JDK (por exemplo, Java 21) e execute o `main` da classe desejada. No exercício de IMC, digite peso em kg e altura em metros, com vírgula decimal. Nos exercícios de strings, digite cada frase ou nome em uma linha.

Consulte [as explicações e exemplos](LEIA-ME.md), incluindo os domínios de entrada e os limites da recursão.

## Verificação

As dez classes foram compiladas com o JDK 21 e verificadas em 22 casos de teste, incluindo expoente zero e os limites de N na sequência de Fibonacci.
